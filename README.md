# UKW PIO Lab Demo

Minimal .NET demonstration project used during laboratory classes for the
"Podstawy Inżynierii Oprogramowania" course at UKW.

The repository is used by the instructor to demonstrate selected Software
Engineering practices throughout the course.

It starts as a minimal .NET console application and may evolve during
subsequent labs as new engineering practices are introduced.

This is a demonstration repository, not the students' semester project.

## Build

```bash
dotnet build ukw-pio-lab-demo.sln
```

## Run

```bash
dotnet run --project src/Ukw.Pio.LabDemo/Ukw.Pio.LabDemo.csproj
```
